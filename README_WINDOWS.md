# تشغيل عيادة ClinicFlow كبرنامج Windows

لقد تم إعداد النظام ليعمل كتطبيق سطح مكتب (Windows App) مع الاحتفاظ بكافة البيانات محلياً على جهازك الخاص.

## المتطلبات الأساسية
1. تثبيت **Node.js** (نسخة 18 أو أحدث) من [nodejs.org](https://nodejs.org/).
2. تحميل ملفات المشروع إلى جهازك.

## خطوات التشغيل لأول مرة
افتح موجه الأوامر (Command Prompt) أو PowerShell في مجلد المشروع ونفذ الأوامر التالية:

1. **تثبيت المكتبات:**
   ```bash
   npm install
   ```

2. **تشغيل التطبيق (نسخة المطور):**
   ```bash
   npm run electron:dev
   ```

3. **إنشاء ملف تثبيت (Installer .exe):**
   للحصول على ملف `ClinicFlow Setup.exe` لتثبيته كأي برنامج آخر على ويندوز:
   ```bash
   npm run build:win
   ```
   *بعد انتهاء الأمر، ستجد ملف التثبيت في مجلد `release/`.*

## مميزات نسخة الويندوز المحلية
* **البيانات محلية:** يتم تخزين جميع المرضى والمواعيد في مجلد `data/` داخل المشروع وليس على الإنترنت.
* **السرعة:** استجابة فورية للعمليات لأن الخادم يعمل على نفس الجهاز.
* **الخصوصية:** بياناتك لا تغادر جهاز الكمبيوتر الخاص بك.

## تخصيص الخادم المحلي
* يتم تخزين قاعدة البيانات في ملفات `.db` داخل مجلد `data`.
* يمكنك أخذ نسخة احتياطية من هذا المجلد في أي وقت لضمان سلامة بياناتك.
